Hamare project ka complete workflow
Client Documents

Bank statement, bill, identity proof

1. File Validation

File safe hai? Valid format hai? Size allowed hai?

2. Duplicate Detection

Kya yeh document pehle submit ho chuka hai?

3. Classification & Extraction

Document type identify aur required fields extract.

4. Identity & Evidence Validation

Client identity, document source aur evidence quality check.

5. Readiness Report

Required evidence complete hai, missing hai ya human review chahiye.




intake.py	Document receive karta hai aur file safety check karta hai.
classification.py	Identify karta hai ke document bank statement hai ya utility bill.
extraction.py	Document se required information nikalta hai.
governance.py	Client identity, evidence source aur trust level verify karta hai.
config.py	Configuration aur rules validate karta hai.
readiness.py	Check karta hai ke service ke liye evidence complete hai ya nahi.
main.py	Sab stages ko ek workflow mein execute karta hai. 



Day 1 mein pehli batch documents process hoti hai. Is mein duplicate files, invalid files, aik doosre client ka document, aur missing bank-statement months jaise test cases hain. Tool inhein check karke batata hai kya accept, reject, review, ya quarantine karna hai.

Day 2 mein pehle missing bank statement aur passport aate hain, aur corrected bank statement aur W-2 bhi. Tool corrections ko purani files se jorta hai, purani versions ka record rakhta hai, aur phir readiness dobara check karta hai.
